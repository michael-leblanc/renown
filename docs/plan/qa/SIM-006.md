# QA SIM-006: PASS

All 6 acceptance criteria have tests that assert the behaviour. Non-critical task, so I did not run a red proof.

- Turns: NPC i thinks when the brain's tick count mod the interval equals i mod the interval. The tests check 100 NPCs thinking exactly once in 10 ticks and exactly 10 per tick over 25 ticks.
- Edge cases: `ticks()` clamps the interval to at least 1, so a changed tick rate and a zero interval are both safe. Removed characters are skipped, and an empty world returns early.
- Domain rules: no nodes. The only randomness is `sim.rng`. The numbers come from `settings.json`. There is no player-only or NPC-only branch.
- Minor, not a failure: `step()` reads `sim.world._characters`, a private field.
