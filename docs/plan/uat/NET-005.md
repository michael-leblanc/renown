# UAT NET-005 — Two players see each other only while in sight

⏱ ~20 min · 📍 desktop 1 (Linux) and your Mac, same home network

## What changed
You can start the server and the game with two scripts, and two games on two machines share one world with 32 wandering NPCs.

## Before you start
- Both machines have the repo on this task's branch (`git pull`). The first run on each downloads Godot 4.7.2 (once).
- Mac can't connect? Open UDP port 24600 in desktop 1's firewall. A server restart is a new world (no saving yet).

## Test it
- [ ] **Desktop 1: run `scripts/server.sh`, then in a second terminal `scripts/play.sh --address=127.0.0.1`** → the server prints its addresses and `listening on port 24600`; the game opens inside the world with a character and NPCs walking about.
- [ ] **Mac: pull, then run `scripts/play.sh --address=<desktop 1 address from the server's list>`** → a second character appears next to the building, and each screen shows the other player.
- [ ] **Click to walk, then click the door of the building** → your character walks, the door opens and you step inside; the other screen shows it.
- [ ] **Watch the NPCs for a minute** → they wander between tiles, walk through the open door and none jump or freeze.
- [ ] **Walk one player behind the building (north side), away from the other** → the other player's character vanishes from your screen; walking back out makes them appear again.
- [ ] **Close the Mac game, reopen it with the same command within 30 seconds** → you are back on the same character where you left it.
- [ ] **Close it again, wait over 30 seconds, reopen** → a character stands on the free tile nearest where you left.
- [ ] **Press F3 on each screen** → frames a second shows; then tell Claude what felt wrong or should change.

## Not in this task
- No Windows start script, no saving, no names or stats, no roof, no fighting.
