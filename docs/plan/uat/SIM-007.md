# UAT SIM-007 — Measure the tick time for N NPCs on a headless server

⏱ ~30 min (mostly waiting) · 📍 a terminal on desktop 1, PowerShell on desktop 2

## What changed
The repo can now time the server's tick with 32 up to 8000 NPCs and give an NPC budget for the PC it runs on.

## Before you start
- Close everything heavy on the PC: no build, no stream, no game, no browser video. The numbers get worse otherwise.
- Desktop 1 needs the repo checked out on `main`. Desktop 2 needs only the two downloads below.

## Test it
- [ ] **Desktop 1 (Linux): in the repo, run `scripts/measure.sh`** → 8 lines (`32 NPCs: average … ms, worst … ms, hash …` up to `8000 NPCs`), then `budget: …`, `cpu: …`, `os: …`, `godot: 4.7.2-stable`.
- [ ] **Desktop 1: paste the whole output back to Claude** → the budget line, the CPU name and the hashes are all in it.
- [ ] **Desktop 2 (Windows): download `Godot_v4.7.2-stable_win64.exe.zip` from `https://github.com/godotengine/godot/releases/tag/4.7.2-stable` and unzip it into `C:\renown-measure\godot`** → `Godot_v4.7.2-stable_win64_console.exe` is there (the console one prints to PowerShell).
- [ ] **Desktop 2: on GitHub, press Code → Download ZIP for the repo and unzip it so the repo's files sit directly in `C:\renown-measure\repo` (move them up out of the zip's one top folder)** → `C:\renown-measure\repo\game\project.godot` exists.
- [ ] **Desktop 2: in PowerShell run the one command below** → it imports the project, then prints the same 8 lines and the budget, CPU, OS and Godot version.
- [ ] **Desktop 2: paste the whole output back to Claude** → both outputs are now in the chat.
- [ ] **Compare the `hash` column of both outputs** → every count has the same hash on both PCs.

```powershell
$g = "C:\renown-measure\godot\Godot_v4.7.2-stable_win64_console.exe"; $p = "C:\renown-measure\repo\game"; & $g --headless --path $p --import | Out-Null; & $g --headless --path $p -s tools/measure.gd
```

## Try to break it
- [ ] **Desktop 1: run `scripts/measure.sh --count=32`** → only the `32 NPCs` line prints, nothing else.

## Not in this task
- No NPC number is final: the budget is read from your two outputs, the slower PC sets it (D178).
- The stand-in NPCs only wander and look around, so real NPCs will cost more. No combat, sending to clients or saving yet.
- Godot may print a leaked-objects warning at the end of a run. It is harmless.
- The two towns overlap at 4000 and 8000 NPCs: one NPC per 100 tiles doesn't fit on the map any more.
